# Rock Paper Scissors Game

A simple, interactive Rock Paper Scissors web game built with HTML5, CSS3, and Vanilla JavaScript. Play against the computer, track live scores, and see dynamic visual feedback for wins, losses, and ties.

---

## Features

- **Interactive Gameplay:** Click on Rock, Paper, or Scissors icons to make a move.
- **Randomized Computer AI:** The computer selects an option randomly each round.
- **Real-Time Score Tracker:** Tracks both player and computer scores dynamically during the session.
- **Dynamic Feedback Banner:** Color-coded status alerts:
  - 🟢 **Green:** You win
  - 🔴 **Red:** Computer wins
  - 🟡 **Yellow:** Tie game
- **Hover Effects:** Visual opacity cues when hovering over playable choices.
